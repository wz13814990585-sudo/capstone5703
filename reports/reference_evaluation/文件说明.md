# 模型评估与回测章节材料

此文件夹汇集项目报告中模型评估与回测章节的写作材料。

- 模型评估报告.md：章节文字底稿，含方法、结果和局限。
- model_evaluation.csv：预测能力指标。
- strategy_comparison.csv：模型、策略、窗口和费用的回测结果。
- strategy_rules.json：15种组合策略规则。
- coverage.csv：预测序列的时间覆盖。
- phase_sensitivity.csv：低频调仓起始周敏感性。
- official_model_status.csv：原始模型配置的有效状态。
- verification.json：独立核查结果。
- charts/：净值、回撤等图表；正文按分析需要选取。
- 核心代码参考/：核心回测代码、策略定义与原项目说明。

建议章节结构：评估设置、预测能力、组合策略、回测结果、稳健性与局限。

核心代码参考仅用于解释实现，并非完整可独立运行的项目。完整复现仍需原项目中的数据、训练与恢复脚本及其他依赖。所有材料均复制自最终完整历史结果，原文件保留。
